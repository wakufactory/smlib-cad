テキストコマンド一覧

1行に1命令。# 以降はコメント。[…] は省略可能な引数です。名前は英字・下線で始め、英数字・下線を使います。角度は度数です。

x y z は位置、dx dy dz は軸方向（省略時は +Z）、ux uy uz は断面のX方向です。

box
名前 x y z 幅 奥行 高さ
sphere
名前 x y z 半径
cylinder
名前 x y z 半径 高さ [dx dy dz]
cone
名前 x y z 底面半径 上面半径 高さ [dx dy dz]（上面半径 0 で円錐）
torus
名前 x y z 主半径 管半径 [dx dy dz]
pyramid
名前 x y z 底面の辺長 高さ [dx dy dz]
cylindrical_box
名前 x y z 高さ 内半径 外半径 開始角 終了角 [dx dy dz]
partial_sphere
名前 x y z 半径 開始角 終了角 [dx dy dz]
partial_cone
名前 x y z 底面半径 上面半径 高さ 開始角 終了角 [dx dy dz]
partial_cylinder
名前 x y z 半径 高さ 開始角 終了角 [dx dy dz]
partial_torus
名前 x y z 主半径 管半径 開始角 終了角 [dx dy dz]
ellipsoid
名前 x y z X半径 Y半径 Z半径
sphere_no_pole
名前 x y z 半径
plane
名前 x y z X長さ Y長さ（面）
planar_circle
名前 x y z 半径（面）
profile / polygon / spline / end
profile 断面名 内に polygon u1 v1 ...、または spline through u1 v1 ... closed を1行記述して end で閉じる。スプラインは通過点4〜64組。同じ点を隣接して2回書くと角になる
extrude
名前 断面名 x y z 開始距離 終了距離 [dx dy dz [ux uy uz]]
revolve
名前 断面名 x y z 開始角 終了角 [dx dy dz [ux uy uz]]（度数）
union / subtract / intersect
出力名 左の形状名またはグループ名 右の形状名またはグループ名
chamfer
形状名 幅（その形状の全エッジを面取り）
fillet
形状名 半径（その形状の全エッジを丸め）
offset
形状名 距離（正は外側、負は内側）
shell
形状名 厚み [開口面の番号 ...]（正は外側、負は内側。面指定なしは閉じた中空体）
faces
形状名（現在の面番号と各面の座標範囲をログへ表示）
material
形状名 baseColorのR G B metallic roughness
part / end
ルート階層で part 部品名 から end までを再利用可能な定義にする
use
use 部品名 [配置名] で部品を新しく生成する
group / end
group 名前 から end までをローカル座標のグループにする。入れ子可
scale
グループ内で scale sx sy sz（各軸の正の倍率）
euler
グループ内で euler rx ry rz（度数）
position
グループ内で position x y z（親座標での移動）
let
let 名前 = 式（数値変数。${式} を数値引数や形状名に埋め込める）
for / end
for i in range(回数) または range(開始, 終了[, 刻み])。end で閉じる。終了値を含まない
tessellation
形状名 曲面精度 角度条件（形状ごとの指定。曲面精度は 0.001〜2、角度は 1〜90。default でUI設定を使用）

例：穴のある箱

box body 0 0 0 20 20 8
cylinder hole 10 10 -1 3 10
subtract result body hole

Boolean は左右の入力を消費し、出力名に結果を作ります。材質の RGB・metallic・roughness は 0〜1。グループの変換は scale → euler → position の順です。

度 · 大きいほど粗い

拡張子は自動
ドラッグ: 回転 · ホイール / ピンチ: ズーム · ダブルクリック: 視点を戻す
